# ADR-005：以 Markdown 清單作為輸入與輸出（待處理區 + APA 7 表格）

- **狀態**：Accepted <!-- Proposed | Accepted | Superseded by ADR-NNN -->
- **日期**：2026-10-20
- **Agent**：`claude-code`
- **任務**：`TASK-001`

## 1. 背景與問題

使用者希望在同一個 md 檔持續加入文獻（可只給作者與標題），執行時只處理未處理的條目，並取得完整 APA 7th 清單。

## 2. 評估過的方案

| 方案 | 優點 | 缺點 |
|---|---|---|
| A：APA 文字檔輸入 + 另外的 report.md | 簡單 | 輸入和輸出分開，無法持續增加、無法只處理新條目 |
| B：單一表格，使用者在表格最後加列 | 輸入輸出同一處 | 要自己打表格符號，容易打錯 |
| C：「待處理」區（每行一筆，任何格式）+ 程式維護的 APA 7 表格；狀態存在同名 JSON | 新增方便、只處理新條目、輸出完整 APA 清單 | 表格由程式重寫，手動修改表格內容會被覆蓋（除狀態欄的「重試」與刪除整列） |

## 3. 決策與理由

選 C（使用者確認）。
- 檔案：`DATA_DIR/input/references.md`（使用者編輯）與 `references.json`（程式狀態：DOI、類型、key、狀態、來源）。
- 每次執行：讀 md → 套用使用者編輯（刪列＝移除、狀態「重試」＝重新處理）→ 辨識新條目（完整 APA、作者＋標題、標題、DOI；Crossref + OpenAlex）→ 產生 APA 7 → 只下載待處理（`--interactive` 時也含需人工處理）→ 寫回狀態、檔案連結、備註（中文）。
- APA 7：由書目資料產生（作者最多 20 位、句首大寫、期刊與卷斜體、頁碼 en dash、DOI 網址）；使用者給的 APA 標題大小寫會保留；查不到的書照使用者的 APA 重寫並將書名改斜體。年份以期刊卷期（印刷）年份為準。
- 表格依 APA 字母順序排列。

## 4. 影響與代價

- 取代原本的 `references.txt` → `report.md` 流程（相關程式已移除）。
- 句首大寫無法辨識專有名詞（人名、地名會變小寫），產生的 APA 仍需人工快速檢查；以標題搜尋配對的條目會註明「請確認」。
